## 3. 超新星データの選択

- 合計55万実現（n=2000 で40万、n=8000 で10万、ほか5万は n=8000 の α=0.009）で、BAO+超新星で Δχ²<9 になった実現：

| 組み合わせ | Δχ²<9 の実現 |
| --- | --- |
| BAO+Pantheon+ | 0 |
| BAO+Union3 | 1（上記の実現、+7.0） |
| BAO+DES-SN5YR | 1（上記の実現、−10.2） |
| BAO+DES-Dovekie | 1（上記の実現、+2.0。Dovekie はこの実現でのみ評価） |

- 生存率（BAO+超新星、Δχ²<9、全実現比）：Pantheon+ では < 5.5×10⁻⁶（95%上限、3/55万）。Union3 と DES-SN5YR では約 2×10⁻⁶（55万中1個。95%区間はおよそ 5×10⁻⁸〜1×10⁻⁵）。
- 結論は超新星データの選択に依存するが、どの選択でも生存率は 10⁻⁵ 以下。
- 補足：Dovekie での全実現の評価は未実施（BAO で Δχ²<60 の実現だけを再評価すれば十分安く済む）。

## フェーズ4のまとめ

- **CMB を含めれば、モデル1（S₀=0、再結合期の抑制なし）は明確に棄却**（パイロット約1万2千実現で最良 Δχ²=+466、BAO+DES-SN5YR に合う唯一の実現も θ* が 6.6% ずれる）。
- **CMB を使わず DESI BAO＋超新星だけなら、生存率は 10⁻⁶〜10⁻⁵ 程度**で、超新星データ次第で「ほぼゼロ」から「約50万分の1」まで変わる。生き残る実現は、現在の Ω_m ≈ 0.6 と過去の強く負の Λ という、他の観測と相容れない宇宙。
- 刻み幅は完走率には効くが、Δχ² の分布の裾にはほとんど効かない。
- 再結合期の Λ に上限を課す版は、上記の実現が CMB で桁違いに外れることから、結論を変えないと判断し、実施を見送る（必要ならまとめの段階で補足として行う）。
