# フェーズ2 記録：モデル1の実装と先行研究の再現（2026-09-30）

## 実装（src/everpresent.py）

- 式は Das et al. I（arXiv:2304.03819）§3–4 と II（arXiv:2307.13743）§2.1。
  - V = (4π/3)∫dτ' a⁴(τ−τ')³（過去光円錐の体積）
  - S_i = S_{i−1} + α√ΔV ξ_i、Λ_i = 8πS_i/V_i
  - H² = ω_m a⁻³ + ω_r a⁻⁴ + Λ/3（第1フリードマン方程式のみ）
- 単位：c=1、1/H100。Λ ∝ 1/√V なのでプランク長は式から消え、H100² 単位で直接計算できる。
- 体積は4つの累積積分への展開で各ステップ O(1)。直接の二重積分と 10⁻¹³ で一致し、桁落ちはない。
- 多数の実現をベクトル化して同時に進める。3000 実現 × 1万ステップで約10秒。
- 選べる設定：刻み方（'das'＝a 等間隔 a_i=i/n、'loga'＝ln a 等間隔）、開始時刻 a_init、体積の扱い（'full'＝厳密、'das'＝V₀ を分母に定数で足す方式）、刻み内の小刻み数。

## 再現の目標（Das et al. I §5.1、図2）

ω_m h² = 0.14、S₀ = 0、z ≈ 10⁴ から開始、各 α につき1万実現。

| --- | --- | --- |

- 分布の性質は再現できた。
  - H₀ の平均：37.8〜42 km/s/Mpc（論文：約40）
  - Ω_Λ0 の平均：ほぼゼロ
  - H₀⁴V の中央値：0.035〜0.042（論文：約0.033）
  - 完走した実現のうち H₀ ∈ [67,72] に入る割合は、α=0.01 で約0.5%、α=0.012 で2〜4%
- 完走率は、ln a 等間隔 n=2000 と厳密な体積の組み合わせで論文と 1〜2σ 以内。
- 判定（暫定）：**定性的な再現は達成**。ただし下記の離散化依存が未解決。

## 発見1：a 等間隔の粗い刻みは、初期に人工的な破綻を生む

- a 等間隔で a=1e-4 から始めると、最初の数ステップで a が2倍、1.5倍と進む。
- 刻みの中では Λ を一定に保つので、その間に ρ（放射・物質）が約1/4〜1/5 に落ちると、刻みの開始時点で x = Λ/(3ρ) ≈ −0.2 程度でも途中で H² < 0 になる。
- α=0.005 の破綻の99%が最初の10ステップ以内（a < 1.1e-3）に集中していた。
- Das et al. I §5.2 の「刻みを細かくすると破綻が減る」という記述は、主にこの効果を指していると解釈できる。

## 発見2：細かい刻みの極限でも完走率は収束していない（要検討）

- ln a 等間隔で n を 2000 → 8000 にすると、α=0.01 の完走率は 0.347 → 0.287 に下がる。
- 解釈：S は体積 V を「時間」とするブラウン運動なので、Λ の分布そのものは刻みに依存しない。しかし「H² < 0 になったかどうか」は初到達の事象なので、細かく判定するほど多く捕まる（連続極限ではさらに増える可能性がある）。
- つまり破綻率（とそれによる生存者の選択）は、モデル1の定義だけでは一意に決まらず、刻みの取り方に依存する。
- Das et al. の「細かくすると減って一定値に収束する」という主張とは逆向きの傾向。先行研究の数値が特定の刻みに依存している可能性がある。
- 本研究への影響：生存率は「破綻しなかった実現」の中で数えるので、刻みの選択が結論に効きうる。フェーズ4の頑健性項目に「刻み幅（n と刻みの種類）」を正式に加える。フェーズ3の基準設定は ln a 等間隔 n=2000、z=10⁴ 開始、厳密な体積とする。

## 発見3：放射優勢期は揺らぎが相対的に大きい

- 解析的に、放射優勢期では H⁴V = (4π/3)/280 ≈ 0.0150、物質優勢期では約0.033。
- したがって x = Λ/(3ρ) の典型値は放射優勢期の方が約1.5倍大きい（α=0.005 で 0.34 と 0.23）。
- 開始を z=10⁶ にすると、α=0.008 で7割以上が z ~ 10⁵ で破綻した。Das et al. が z=10⁴ 開始を選んでいるのはこのため。
- 開始赤方偏移もモデルの恣意的な選択の一つで、頑健性項目に入れる。

## 追加検証1：刻み幅の収束（α=0.01、各4000実現、ln a 等間隔、z=10⁴ 開始、厳密な体積）

| n | 完走率 | 生存者の H0 平均 | 全実現に対する H0∈[67,72] の割合 |
| --- | --- | --- | --- |
| 250 | 0.314 ± 0.007 | 39.6 | 0.0012 |
| 500 | 0.371 ± 0.008 | 39.9 | 0.0025 |
| 1000 | 0.363 ± 0.008 | 39.9 | 0.0010 |
| 2000 | 0.335 ± 0.008 | 40.0 | 0.0013 |
| 4000 | 0.291 ± 0.007 | 39.4 | 0.0015 |
| 8000 | 0.266 ± 0.007 | 40.4 | 0.0005 |
| 16000 | 0.231 ± 0.007 | 39.9 | 0.0018 |
| 32000 | 0.219 ± 0.007 | 40.2 | 0.0005 |
| 64000 | 0.196 ± 0.006 | 39.7 | 0.0010 |

- n ≥ 2000 では、f(n) = f∞ + c/√n によく合う（χ² = 3.9、自由度4）。これは離散的な監視で初到達を見逃す場合の標準的な補正の形。
- **連続極限の完走率は f∞ = 0.174 ± 0.005**。Das et al. の 0.323 は、特定の刻みでの値と解釈するのが妥当。
- 生存者の H0 分布と、全実現に対する「観測並みの H0」の割合は、刻みにほぼ依存しない。
- 結論：破綻率は刻みに依存するが、その依存は理解できる形（√刻み幅）をしている。生存率の分母を「全実現」にする場合は、破綻率の刻み依存が結果に直接効くので、頑健性の項目として扱う。

## 追加検証2：Ω_Λ の自己相関（Das I 図8、α=0.01、生存 2007 実現）

- exp(−c₁Δλ^c₂) の当てはめ：c₁ = 3.62, c₂ = 0.44（論文：3.2, 0.48）。形は再現できた。
- ただし Ω_Λ = Λ/(3H²) は H² → 0 付近で発散的に大きくなり、上位0.1%の値が二乗和の49%を占める。図8の「短い時間差での急な落ち込み」は、この外れ値によるところが大きい。
- 外れ値の出にくい x = Λ/(3ρ_m+r) で測ると、相関は Δλ = 0.1, 0.3, 1.0 で 0.78, 0.54, 0.22。Λ = S/V と S のブラウン運動性から導かれる √(V₁/V₂) ≈ exp(−3Δλ)（0.74, 0.41, 0.05）に近い、ゆっくりした減衰。
- 本研究への示唆：実現の特徴を Ω_Λ の統計で要約すると外れ値に引きずられる。要約には x を使う。

## 背景膨張モジュールへの接続（src/everpresent_bg.py）

- 実現の ω_Λ(z) = Λ(z)/3 の表を Background に渡す。h はモデルの結果として決まる。
- 定数の Λ を渡したとき、通常の ΛCDM の計算と完全に一致（θ*、D_M、r_d）。
- r_d は、実現の H(z)（再結合期の Λ を含む）で音響地平線を積分し、標準ケースでの較正比を掛けて求める。
- 残る近似：z* と z_d は標準の近似式（Λ による再結合時期のずれは無視）。モデル1側は ν を質量ゼロ、Background 側は 0.06 eV として扱うので、ω_m の定義に約0.5%の不整合がある。

## フェーズ2 判定：合格（条件付き）

- モデル1の定性的な振る舞い（H0 の分布、Ω_Λ0 の平均ゼロ、H0⁴V、完走率の傾向、自己相関の形）を再現できた。
- 条件：破綻率の刻み依存（連続極限 0.17 と Das の 0.32 の差）を「モデルの恣意性」として明記し、フェーズ4で扱う。
- モデル2（Zwane et al. 2017）の実装は、フェーズ4の頑健性テストに回す。式は Das I §5.4.1 に記載がある（Ω_Λ = tanh(Ω̂_Λ)、Ω̂_Λ は λ=ln a 上のガウス過程、共分散 α̃² exp(−μΔλ²/2)）。
