## 1. 重複の有無

- DESI DR1/DR2 BAO で Everpresent Λ を本格検証した論文は、ウェブ検索の範囲では見つからなかった。
- 最も近い研究：Gómez, Palma, Cruz, "Observational constraints on Diffusion Cosmologies in Unimodular Gravity from DESI DR2"（arXiv:2609.10574, 2026-09）。同じユニモジュラー重力の枠組みだが、決定論的な拡散モデルで、確率的実現を扱う Everpresent Λ とは別物。
- Das, Nasiri, Yazdi (arXiv:2307.13743) の最新版は v2（2024-10-04）。序論で DESI に言及するが、解析は超新星（Pantheon+SH0ES）と CMB のみで、BAO は未使用。
- 残作業：INSPIRE で arXiv:1703.06265 と arXiv:2307.13743 の被引用論文を手動確認する（検索の網羅性の補完）。

## 2. 設計書に反映すべき点

### 2.1 モデル1の式（Das et al. 2023 §2.1 で確認）

- V_t：時刻 t の観測者の過去光円錐の4次元体積  
  V_t = (4π/3) ∫₀ᵗ dt′ a(t′)³ ( ∫_{t′}^{t} dt″ / a(t″) )³
- 更新式：Λ_t = [ Λ_{t−dt} V_{t−dt} + 8πα ξ_t √(V_t − V_{t−dt}) ] / V_t,  ξ_t ~ N(0,1)
- ρ_Λ = Λ / (8πG)。第1フリードマン方程式 H² = (8πG/3)(ρ_m + ρ_r + ρ_Λ) に入れる。
- H² < 0 となった実現は破棄（正しい力学は未知）。
- 初期条件：ビッグバンではなく放射優勢期に置き、ダークエネルギーなしの放射優勢宇宙で計算した初期体積 V₀ から始める。
- 先行研究での α の範囲：0.001〜0.025。α ≈ 0.012 付近で観測並みの H₀ が最も多く出る（10,000 ステップ分割時）。α > 0.015 では大半が H² < 0 で破綻し、α < 0.005 では H₀ が小さすぎる。
- フェーズ2では、この式を出発点に Ahmed et al. 2004 の原式との一致を確認する。

### 2.2 本研究の新規性の置き方

- 「生存率」（χ² が閾値以下の種の割合）は Das et al. がすでに超新星で使っている。9万個の種のうち、ΛCDM と同程度（χ² ∈ [1481, 1490]）が55個、ΛCDM より良い尤度が16個。
- したがって差分は指標ではなく、次の3点に置く。
  - DESI DR2 BAO を含む同時適合
  - CMB・BBN との同時生存率
  - w₀wₐ 平面への射影
- 超新星のみでは Ω_m がほぼ制約されない（ベイズモデル平均で Ω_m = 0.58 ± 0.19、α = 0.0085 ± 0.0017）。BAO と CMB が Ω_m を固定する役割を担う。

### 2.3 予想される結末の更新

- CMB については、最終散乱面付近の Λ を抑制すると大きく改善するが、それでも χ² は ΛCDM より大幅に大きい（Das et al.）。
- よって結末2（運のいい宇宙）か結末3（棄却）が有力。

### 2.4 空間的揺らぎの制約（設計書の想定より重い）

- "The CMB in a Causal Set Universe"（arXiv:0711.2904）は Barrow 2006 の論点を数値化し、α に約 10⁻⁵ の上限を置く。これは加速膨張の説明には小さすぎる値。
- 本研究は背景膨張のみを扱うため、この制約を回避する仮定（Λ の空間相関の扱い）を結論の前提条件として明記すること。

## 3. 計算コストの見通し

- (η_t − η′)³ を展開すると、V_t は4つの累積積分 I_k(t) = ∫₀ᵗ a³ η′ᵏ dt′（k = 0〜3）で書ける（η は共形時間）。  
  V_t = (4π/3) [ η_t³ I₀ − 3η_t² I₁ + 3η_t I₂ − I₃ ]
- 各ステップの更新は O(1) で済み、1実現あたり O(N_step) で計算できる。
- 注意：η_t と η′ が近いと桁落ちする。実装時に倍精度での精度を検証すること。
