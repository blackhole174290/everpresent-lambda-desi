## 1-a. DESI DR2 BAO 単独・ΛCDM（完了 2026-09-30）

- 方法：平坦 ΛCDM、自由パラメータは Ω_m と h·r_d。平坦事前分布の 201×201 格子で事後分布を計算（src/run_lcdm_bao.py）。
- 放射は Ω_r h² を固定（h = 0.68 と置いた微小項）。

| 量 | 本パイプライン | DESI 公表値 | ずれ |
| --- | --- | --- | --- |
| Ω_m | 0.2975 ± 0.0086 | 0.2975 ± 0.0086 | +0.00σ |
| h·r_d [Mpc] | 101.53 ± 0.74 | 101.54 ± 0.73 | −0.01σ |

- χ²_min = 10.29（13点、自由度11）
- 判定：合格。BAO 尤度と距離計算は正しい。

## 1-b. 超新星単独・ΛCDM（完了 2026-09-30）

- 方法：平坦 ΛCDM。絶対等級と H₀ の縮退した定数オフセットを解析的に周辺化し、Ω_m の1次元格子で計算（src/run_lcdm_sn.py）。
- 距離：d_L = (1+z_hel) D_M(z_HD)。
- 各データの扱い（Cobaya の実装に合わせた）：
  - Pantheon+：z_HD > 0.01 の 1590 点、m_b_corr と STAT+SYS 共分散（SH0ES 較正は不使用）
  - DES-SN5YR：1829 点、MU、系統共分散に MUERR_FINAL² を対角に加算
  - Union3：22 ビンの圧縮データと共分散

| データ | 本パイプライン | 公表値 | ずれ |
| --- | --- | --- | --- |
| Pantheon+ | 0.3321 ± 0.0182 | 0.334 ± 0.018 | −0.11σ |
| DES-SN5YR | 0.3524 ± 0.0169 | 0.352 ± 0.017 | +0.02σ |
| Union3 | 0.3575 ± 0.0271 | 0.356 (+0.028/−0.026) ※ | +0.06σ |

※ Union3 の公表値は記憶に基づく。Union3.1 論文（arXiv:2601.19424）の「Union3 から −0.3σ ずれて 0.344」という記述と整合することを確認済み。

- 判定：合格。
- 実装メモ：`SupernovaBase.chi2` は任意の E(z) 関数（`E_func`）を受け取れるので、フェーズ3で揺らぐΛの H(z) をそのまま渡せる。

## 1-c. CMB 圧縮尤度と初期宇宙の計算（完了 2026-09-30）

### 圧縮尤度の数値（src/likelihood.py の CMBCompressed）

- 原典：Lemos & Lewis (arXiv:2302.12911) の Planck PR4 CamSpec 早期宇宙チェーン（github.com/cmbant/PlanckEarlyLCDM）。getdist で ignore_rows=0.3 として計算した。
- 平均：θ* = 1.04102739×10⁻²、ω_b = 0.0222321、ω_bc = ω_b + ω_c = 0.1414339
- 共分散は DESI DR2 付録 A の値（二次文献で確認）と完全に一致した。
- 注意：二次文献が「ω_bc = 0.14208」と引用する値は、0.1414339 に ω_ν = 0.06/93.14 = 0.00064 を足した値に一致する。つまり実際にはニュートリノ込みの物質密度。

### 初期宇宙モジュール（src/early.py：quad による参照実装、src/background.py：ベクトル化した本番用）

CAMB 2.0.4 と比較した結果（src/check_early_vs_camb.py、src/check_background.py）：
- z* を CAMB と同じ値にすれば、自作の θ* は CAMB と 0.0001% で一致した。
- Hu–Sugiyama の z* 近似は CAMB より +2.02 ずれている（ばらつき 0.04）。そのままだと θ* が −0.125% ずれ、これは圧縮尤度の1σ（0.025%）の5倍。一定値で補正した。
- Aubourg の r_d 近似は −0.026% の一定のずれ。係数 1.000258 で補正した。
- 音響地平線の積分を z=10⁷ で打ち切ると 0.013% 欠ける。放射優勢期の解析解で補った。
- 最終的な誤差（CAMB 比、30 モデル、ΛCDM と w0wa）：θ* は最大 0.0066%、r_d は最大 0.007%、D_M と D_H は 0.001% 未満。
- 計算時間：1 回 0.3 ms。
- **前提**：z* と r_d の補正は「再結合期の物理が標準的」であることを前提にしている。揺らぐΛが再結合期に大きい実現では成り立たない。フェーズ3では再結合期のΛの割合に上限を課して使う。

## 未解決：CMB 圧縮尤度の ω_bc の定義

- 物理的に整合する定義（モデルの ω_b+ω_c をチェーンの ω_b+ω_c = 0.141434 と比べる）では Δχ² = −6.66。
- モデルの ω_b+ω_c をニュートリノ込みの 0.14208 と比べると Δχ² = −8.10 となり、w0wa の最良点（w₀ = −0.443, wₐ = −1.651）も DESI の値に近づく。θ* の丸めの影響は小さい（−8.15）。
- 解釈は2通りありうる。(1) DESI の実装または二次文献での引用に 0.00064（ω_bc の約1.7σ）の不整合がある。(2) こちらの ω_bc の定義の理解が誤っている。
- 次の一手：DESI DR2 論文の付録 A（PDF の40ページ付近）を直接読んで確定する。desilike と Cobaya の公開リポジトリには該当する数値が見つからなかった（2026-09-30 確認）。判明するまでは、本研究の基準を A（チェーン値）とし、C（0.14208）を頑健性テストの変種として並べる。
- 本研究への影響：CMB を含む生存率の Δχ² 閾値が約1.4ずれうる。結論を述べる際は両方の定義で示す。


### 追記（2026-09-30）：DESI 論文での ω_bc の定義を確認

- DESI DR2 論文の第I節（5ページ）で ω_bc ≡ (Ω_b+Ω_c)h² と定義されている。ニュートリノは Ω_ν h² = Σm_ν/93.14 eV として別に扱われ、ω_bc には含まれない。式(2)の r_d の近似式でも、ω_bc とニュートリノ（N_eff）は別の変数（Babain 確認）。
- 以上から、DESI のモデル側は「ω_b+ω_c（ニュートリノなし）」を圧縮尤度の第3成分と比べていると考えられる。この比較方法は、本パイプラインで DESI の Δχ² = −8.0 と w0wa の値が再現できた変種 C と一致する。
- 残る食い違い：元のチェーン（PlanckEarlyLCDM）では ω_b+ω_c の平均は 0.141434 で、0.14208 はそこに ω_ν = 0.00064 を足した値に一致する。
- 有力な仮説：平均値をチェーンの omegamh2（ニュートリノ込みの派生量）から取り、ω_bc とラベルした。チェーンでは Σm_ν = 0.06 eV に固定されているので ω_ν は定数で、omegamh2 の共分散は ω_b+ω_c の共分散と完全に同じになる。共分散が6桁一致したことと矛盾しない。
- 付録Aの確認結果（Babain）：式(A1)の平均ベクトルの第3成分として 0.14208 が明記されている。算出方法は「Lemos & Lewis (2023) の結果を用いた」「チェーンは github.com/cmbant/PlanckEarlyLCDM」とあるのみで、どの列から取ったかは書かれていない。
- チェーンの margestats で確認した平均値：ombh2 = 0.022232079、omch2 = 0.11920179（和 0.14143387）、**omegamh2 = 0.14207901（丸めると 0.14208 に完全一致）**。
- 結論（確度高）：DESI DR2 付録Aの第3成分 0.14208 は、チェーンのニュートリノ込みの派生量 omegamh2 の平均値であり、DESI 自身の ω_bc（ニュートリノなし）の定義とは 0.00064（約1.7σ）ずれている。DESI の Δχ² = −8.0 は、モデルの ω_b+ω_c をこの値と比べた結果として再現できる（本パイプラインで −8.10）。定義どおりに比べると −6.66。
- 留意：DESI の主要な結論はフル CMB 尤度によるもので、このずれは圧縮尤度を使った結果（表Vの DESI+(θ*,ω_b,ω_bc)CMB の行、表VIの Δχ² = −8.0）に限られる。フル CMB の結果には影響しない。
- 本研究の扱い：基準は A（ラベルどおり ω_b+ω_c を、チェーンの ω_b+ω_c = 0.141434 と比べる）を維持する。DESI の公表値と比べる必要がある場面では C も併記する。影響は Δχ² で約1.4、ω_bc で約1.7σ。

## フェーズ1 判定（2026-09-30）：合格

- 判定基準「Ω_m、H₀r_d、w₀wₐ が DESI 公表値と1σ以内」は、比較したすべての項目で満たした（最大のずれは約0.25σ）。
